# Haqiqiy ovoz montaji

Telefonda yozgan ovozingizni shu papkaga yuklang. Fayl nomi videoning nomi bilan bir xil bo'lsin:

    ovoz-yozuv/stellaj-buyurtma-1101.m4a   ->   reels/stellaj-buyurtma-1101.mp4

GitHub avtomatik montaj qiladi: `reels/stellaj-buyurtma-1101-ovoz.mp4`. Hali chiqmagan post bo'lsa,
`reja/posts.json` da o'zi ovozli versiyaga almashadi.
